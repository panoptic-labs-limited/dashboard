# Examples

Example dashboards demonstrating the Viz framework.

## Running Examples

```bash
# Install the client library
cd ../client
pip install -e .

# Run an example
python ../examples/sales_dashboard.py
```

## Examples

- **sales_dashboard.py**: Basic sales analytics dashboard with date and region selectors
- **multi_page_dashboard.py**: Multi-page dashboard with various chart types
- **advanced_selectors.py**: Demonstrates all selector types and parameter binding
